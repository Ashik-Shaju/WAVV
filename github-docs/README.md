# Wavv documentation

Wavv is an offline-first Android music player. Users choose local audio sources, manage a library and playlists, and play music through Android's media stack.

## Guides

- [Architecture](architecture.md): how library selection, indexing, local storage, discovery, and playback fit together.
- [Privacy and local data](privacy.md): permissions, stored information, and platform backup boundaries.
- [Development and testing](development.md): build entry points and what each test level can establish.
- [Redistribution and notices](redistribution.md): source-license status, bundled notices, and release-signing limits.

Use the root [README](../README.md) for the current Windows prerequisites and exact build commands.
